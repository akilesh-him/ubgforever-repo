# App logo sources

Discord, Spotify, Reddit and Wikipedia path artwork: Simple Icons, downloaded from the repository's `develop/icons/{brand}.svg` files. Local assets retain the actual brand paths with a background for consistent tile sizing. HTML editor is a Slipstream-owned tool and uses a code symbol.

Source: https://github.com/simple-icons/simple-icons

YouTube/Twitch: Simple Icons v15 paths, brand background. Desmos: official https://www.desmos.com/assets/img/apps/graphing/apple-touch-icon.png.
